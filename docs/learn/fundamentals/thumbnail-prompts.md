# Fundamentals Track: Module Thumbnail Prompts

This document provides dedicated, copy-pasteable image generation prompts for each module in the **Fundamentals Track**.
These prompts are crafted specifically for image generators like **Google Flow** and **Imagen 3**, using the official UB Society 3D fluffy creature mascot design system.

---

## Universal Generation Guidelines

Every thumbnail prompt adheres to two non-negotiable visual anchors:
1. **Pure Solid Black Background (`#000000`):** Complete darkness with zero floor planes, zero horizon lines, and zero background clutter, allowing the image to blend into dark mode documentation headers.
2. **UB Society Mascot Consistency:** A round, plump, ultra-fluffy 3D monster creature (Pixar and DreamWorks CGI style) with dense soft fur, huge glossy cartoon eyes, a wide joyful open-mouthed smile showing teeth and tongue, tiny curved head horns, and stubby arms and feet.
3. **Studio Rim Lighting:** Crisp edge lighting and subsurface scattering along the fur silhouette to cleanly separate the bright colorful creature from the pitch-black void.
