# Fundamentals Track: Sub-Module Thumbnail Prompts

This reference document provides dedicated, copy-pasteable image generation prompts for **all 27 individual lessons (sub-modules)** across the **Fundamentals Track**.
Each prompt is crafted specifically for **Google Flow** and **Imagen 3**, strictly enforcing a pure solid black background (`#000000`) and the official UB Society 3D fluffy mascot design language.

---

## Universal Prompt Parameters
- **Background:** Pure solid pitch-black (`#000000`), zero floor plane, zero shadows, zero walls.
- **Aesthetic:** High-end 3D Pixar/DreamWorks character render, dense soft fur with subsurface scattering, huge glossy cartoon eyes, friendly open-mouthed smile.
- **Lighting:** Vibrant studio edge/rim lighting separating the colorful fluffy character from the pitch-black void.
